# Security

If you find a security issue in Agentline NZ, please email [support@agentline.nz](mailto:support@agentline.nz) with "Security" in the subject line. Include what you found and the steps to reproduce it.

Please don't open a public GitHub issue for security problems, and don't access or change other people's data while testing.

You can also reach us through [agentline.nz/contact](https://agentline.nz/contact).
